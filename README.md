# RRT UNIT PORTAL — версия 0.3

Портал отряда Rapid Response Team: вход через Discord, права по ролям отряда, личный кабинет, обучение, опросник и панель администратора для Штаба.

Стиль и оформление версии 0.2 сохранены полностью.

---

## Что нового в 0.3

- **Вход через Discord** — без отдельной регистрации. Сайт читает твои роли на сервере RRT.
- **Доступ по ролям Discord** (проверяется на сервере, а не просто прячется в браузере):

| Роль Discord | Role ID | Что открыто на сайте |
|---|---|---|
| С талончиком | `1533566289627578419` | Только Опросник |
| Рекрут | `1523641828174200937` | Руководство + Обучение + Личный кабинет + Опросник |
| Отряд RRT | `1523641828174200938` | Весь портал, без админ-панели |
| Офицер | `1523641828186919041` | Всё как у Отряда RRT + Офицерский раздел (состав, прогресс, тесты) |
| Штаб | `1523641828199497743` | Полный доступ + Панель администратора |

  Приоритет: Штаб → Офицер → Отряд RRT → Рекрут → С талончиком. Роли обновляются при каждом входе.
- **Личный кабинет** — аватар, ник, Discord ID, роли, прогресс обучения, квалификации.
- **Опросник** — встроенная Google-форма; кнопка «Я заполнил опросник» фиксирует сдачу, Штаб видит дату, ник и статус.
- **Офицерский раздел** — состав и прогресс бойцов (только просмотр).
- **Панель администратора (Штаб)** — обзор, личный состав, ответы на опросники (с пометкой «рассмотрен»), обучение/тесты, роли и доступ, настройки.
- **Логотип RRT** в шапке, на главной, в фоне и как favicon.

## Шаг 1. Выгрузить сайт на GitHub

1. Распакуй архив. Внутри папка `rapidresponseteam.github.io` с файлами:
   `index.html`, `style.css`, `script.js`, `discord-worker.js`, `wrangler.toml`, `README.md`, `assets/`.
2. Открой свой репозиторий `RRTRapidResponseTeam/RRTRapidResponseTeam.github.io` на GitHub.
3. **Add file → Upload files** и перетащи **содержимое папки** (не ZIP!) — в корне репозитория должны лежать `index.html`, `style.css`, `script.js` и папка `assets`.
4. Внизу нажми **Commit changes**. GitHub Pages сам обновит сайт через минуту-две.

## Шаг 2. Создать Discord-приложение

1. Открой https://discord.com/developers/applications → **New Application** → назови, например, `RRT Portal`.
2. Слева **OAuth2**:
   - скопируй **Client ID** и **Client Secret** (понадобятся на шаге 3);
   - в **Redirects** добавь: `https://ИМЯ-ВОРКЕРА.workers.dev/auth/callback` — впишешь точный адрес после шага 3 (его можно добавить и потом).
3. Бот и его токен **не нужны** — роли читаются через OAuth-право `guilds.members.read`.

## Шаг 3. Развернуть Worker на Cloudflare (бесплатно)

1. Зарегистрируйся на https://workers.cloudflare.com (бесплатный план достаточен).
2. **Workers & Pages → Create → Create Worker** → имя `rrt-auth` → **Deploy**.
3. **Edit code**: удали заготовку, вставь всё содержимое файла `discord-worker.js` → **Deploy**.
   Адрес воркера вида `https://rrt-auth.ТВОЙ-САБДОМЕН.workers.dev` — запомни его.
4. **Settings → Variables & Secrets** → добавь (тип Secret, названия точно такими):

   | Имя | Значение |
   |---|---|
   | `DISCORD_CLIENT_ID` | Client ID из шага 2 |
   | `DISCORD_CLIENT_SECRET` | Client Secret из шага 2 |
   | `DISCORD_GUILD_ID` | `1523641828149039249` |
   | `SESSION_SECRET` | любая длинная случайная строка (например, 40+ символов) |
   | `SITE_URL` | `https://rrtrapidresponseteam.github.io` |

5. Вернись в Discord Developer Portal → OAuth2 → Redirects и добавь `https://ИМЯ-ВОРКЕРА.workers.dev/auth/callback`.
6. **KV-хранилище** (чтобы состав и прогресс не сбрасывались): **Storage & Databases → KV → Create namespace** → имя `rrt-data`.
   Затем **Settings → Bindings → Add → KV namespace**: Variable name `RRT_KV`, namespace `rrt-data` → Deploy.
   (Через терминал то же самое делает `wrangler.toml` из архива: `wrangler kv namespace create RRT_KV` и `wrangler deploy`.)

## Шаг 4. Подключить сайт к воркеру

1. Открой `script.js`, в самом верху найди строку:
   `WORKER_URL: "https://rrt-auth.ВАШ-САБДОМЕН.workers.dev"`
   и впиши свой адрес воркера из шага 3.
2. Загрузи обновлённый `script.js` на GitHub (шаг 1) — всё, авторизация работает.

## Шаг 5. Ответы на опросник (видны Штабу полностью)

Сайт всегда показывает Штабу **факт заполнения**: дату, ник и статус («новый» / «рассмотрен»).
Чтобы видеть и **сами ответы**, подключи Google-таблицу один раз:

1. Открой форму → вкладка **Ответы** → зелёная иконка таблицы — «Связать с Google Таблицами».
2. В созданной таблице: **Файл → Поделиться → Опубликовать в интернете** → тип: **Значения, разделенные запятыми (CSV)** → Опубликовать.
3. Скопируй ссылку публикации и добавь её в воркер как секрет `GOOGLE_SHEET_CSV_URL` (Settings → Variables & Secrets).

## Как пользоваться

- **Боец**: заходит на сайт → «ВОЙТИ ЧЕРЕЗ DISCORD» → портал сам открывает разделы по его ролям. Личный кабинет показывает роли и прогресс; опросник — со встроенной формой.
- **Штаб**: Панель администратора → «Личный состав» — отмечает галочками сданные тесты (кнопка «Сохранить прогресс»); «Опросники» — таблица заполнивших и ответы из Google-таблицы, клик помечает «рассмотрен».
- После выдачи/смены роли в Discord боец просто перезаходит на сайт — доступ обновится.

## Файлы

- `index.html` — все страницы портала
- `style.css` — стиль (без изменений с версии 0.2 + стили новых разделов)
- `script.js` — логика: вход, роли, кабинет, опросник, админ-панель
- `discord-worker.js` — серверная часть для Cloudflare Workers (секреты только там)
- `wrangler.toml` — конфиг для деплоя воркера через терминал
- `assets/` — логотип и favicon
